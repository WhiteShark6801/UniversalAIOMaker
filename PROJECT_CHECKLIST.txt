Build

Runtime requirements
--------------------
- 7z.exe for extracting input ISO files
- lh.bif for Longhorn boot images (include in the separate Required ZIP)
- xorriso.exe for creating the output ISO
- Windows tools including DISM, BCDEdit, takeown, and icacls
- Required boot files and scripts for the selected media types

Do not add generated output, Windows installation ISOs, or third-party tools
and boot files to a public repository unless their redistribution terms allow it.
See README.md for project licensing notes and runtime details.
