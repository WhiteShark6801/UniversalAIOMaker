  NAVIGATION FLOW
═══════════════════════════════════════════════════════════════════

Main Menu
    ├─ Press 1 → Windows NT x86 Sub-Menu (Page 1)
    │   ├─ Press 1-9 → Boot selected OS
    │   ├─ Press 0 → Windows NT x86 Sub-Menu (Page 2)
    │   │   ├─ Press 1-6 → Boot selected OS
    │   │   └─ Press B → Back to Main Menu
    │   └─ Press B → Back to Main Menu
    │
    ├─ Press 2 → Windows NT amd64 Sub-Menu
    │   ├─ Press 1-5 → Boot selected OS
    │   └─ Press B → Back to Main Menu
    │
    ├─ Press 3 → Windows 9x Sub-Menu
    │   ├─ Press 1-3 → Boot selected OS
    │   └─ Press B → Back to Main Menu
    │
    ├─ Press 4 → Boot Windows Vista/Later directly
    │
    └─ Press Esc → Boot to hard drive (Default after 30s timeout)

═══════════════════════════════════════════════════════════════════
  KEY FEATURES
═══════════════════════════════════════════════════════════════════

✓ Hierarchical menu structure with category sub-menus
✓ Each category is a separate sub-menu
✓ Up to 9 entries per page (numbered 1-9)
✓ Press '0' for next page when more than 9 entries
✓ Press 'B' to return to main menu from any sub-menu
✓ Main menu only shows categories with ISOs present
✓ Entry counts shown in main menu: "Windows NT x86 (15 editions)"
✓ Multi-page support for large collections
✓ 30-second timeout returns to main menu, then boots hard drive
✓ Clean, professional formatting throughout
